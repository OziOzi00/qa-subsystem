# 知识问答子系统集成汇报流程图素材

本目录保存系统集成汇报 PPT 可直接插入的 SVG 流程图。SVG 使用 16:9 画布，中文文字已写入图内，适合直接插入 PowerPoint 后缩放使用。

## 文件说明

| 文件 | 用途 |
|---|---|
| `integration-overall-architecture.svg` | 总体集成架构图：App、知识问答、MySQL、Neo4j、后台管理 |
| `qa-integration-main-flow.svg` | 12 步知识问答集成主流程图 |
| `three-subsystem-integration-flows.svg` | App、知识图谱、后台管理三条对接链路 |
| `integration-problems-solutions.svg` | 集成问题与解决思路 |
| `integration-verification-result.svg` | 集成验证结果页 |

## 使用建议

1. 在 PPT 中选择“插入 -> 图片”，直接选择对应 SVG 文件。
2. 若需要修改文字，建议在 PPT 中覆盖文本框，而不是直接改 SVG。
3. 如果学校电脑不能正常显示 SVG，可先在浏览器中打开 SVG，再导出或截图为 PNG。
