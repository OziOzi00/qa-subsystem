# Mermaid 集成流程图

本目录保存知识问答子系统集成汇报的 Mermaid 源文件。

| 文件 | 内容 |
|---|---|
| `01-overall-integration.mmd` | 总体集成流程 |
| `02-app-integration.mmd` | 与 App 子系统集成流程 |
| `03-knowledge-graph-integration.mmd` | 与知识图谱子系统集成流程 |
| `04-admin-integration.mmd` | 与后台管理子系统集成流程 |

如需导出 SVG，可使用 Mermaid CLI：

```bash
mmdc -i 01-overall-integration.mmd -o 01-overall-integration.svg
```
